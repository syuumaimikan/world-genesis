# World Genesis: システム設計仕様書 (Architecture Specification)

## 1. コア設計思想

- **非スクリプト型創発シミュレーション**: 固定イベントを持たず、全事象は物理・気候・生態・社会・経済の数理モデルの連鎖から自然発生する。
- **因果有向グラフ (Causality DAG)**: 全ての重大イベント（地震、飢饉、価格暴騰、王の死、革命、戦争）は先行原因ノードへの参照を保持する。
- **階層型シミュレーションLOD**: プレイヤー周辺の詳細計算（LOD0）から、国家・惑星単位の集約計算（LOD3）までを多段階クロックでスケジューリングする。

## 2. クレート構成

1. `genesis-core`: 時間クロック、イベントバス、因果グラフ、空間分割ハッシュ、Modローダー。
2. `genesis-geology`: プレートテクトニクス、ナビエ・ストークス近似水理侵食、熱的タラス崩落、鉱物生成。
3. `genesis-climate`: クラウジウス・クラペイロン近似湿度、3胞循環風配図、日射量計算、熱塩海洋循環。
4. `genesis-life`: ロトカ・ヴォルテラ生態系モデル、バイオーム分類、遺伝的形質対立遺伝子。
5. `genesis-civilization`: 王朝系図、長子相続、継承危機、多国間戦争、文化漂移、宗教分裂、技術伝播。
6. `genesis-economy`: 多段階生産チェーン、需給価格均衡オーダーブック、国家独自通貨、為替Forex市場。
7. `genesis-renderer`: 3D頂点メッシュ生成、天体ライティング、軌道カメラ。
8. `genesis-ui`: リアルタイムHUD、価格履歴チャート。
9. `genesis-sim`: 統合シミュレーションループ、Zstd圧縮永続化、インタラクティブ操作エンジン。
10. `genesis-tools`: ヘッドレス世界生成・バッチ実行・性能ベンチマークCLI。
